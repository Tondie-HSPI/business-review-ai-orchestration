# Original technology E&O sample data

This portfolio example uses an original questionnaire and fictional business record. No insurer application or form text is included. The questions model common intake decisions: explain operations, map revenue, identify client system access and contractor exposure, ask for missing claims history, and prepare a packet for human review.

- `data/original_technology_eo_questions.json`: original question schema with invented `sample_` field identifiers.
- `data/synthetic_technology_eo_account.json`: fictional Example-Only Technology Business LLC record.

The current browser workflow is optimized for restaurant/liquor liability. Its question uploader can read this schema, but the full technology E&O readiness and PDF mapping workflow is **not yet implemented** in this repository. The application support example in [Coverage Clarity](https://github.com/Tondie-HSPI/Certificate-and-Coverage-Clarity) contains technology E&O review logic. Keep that distinction explicit in portfolio demonstrations.

Any production carrier submission would require the current carrier form and a qualified reviewer's approval. This sample is independent and does not claim affiliation with an insurer.
